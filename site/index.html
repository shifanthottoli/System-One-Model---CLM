Generating versus choosing

Why write when you can choose?

A normal LLM writes

The → best → action → is → jump

One forward pass per output token. Then your code reads the text to find the choice.

A System One model scores

jump 0.97 · duck 0.02 · run 0.01

No output tokens. A probability for every option, directly.

The trade: it cannot invent an option you did not give it.

The probabilities are an illustration.

The whole loss

Six lines of code

s = F.normalize(state_head(q), dim=-1)
a = F.normalize(action_head(ans), dim=-1)

logits = scale * s @ a.T            # the table
logits = hide_same_document(logits) # related answers are not wrong
labels = torch.arange(len(s))       # the diagonal

loss = (F.cross_entropy(logits, labels) + F.cross_entropy(logits.T, labels)) / 2

Sanity check: the first step should cost ln(batch size). At 16,384 that is 9.70, and our first step measured 9.7053.

What runs, and what is cached

One decision at step tCost
0Before play: each action → Qwen → action head → cacheOnce per action text
1Build the state: context, then questionNothing
2New state → Qwen → state headThe slow step
3Dot product with every cached action vectorAlmost free
4Softmax, take the highest, actAlmost free

The training answers are gone. The cache holds your application’s actions, and they can be text it never saw. That is zero-shot.

What is DeepSWE?

Pick the attempt that actually works

A coding benchmark. An agent attempts real software tasks, and a test suite decides pass or fail.

Real held-out tasks
fastapi-implicit-head-options
httpx-multipart-response-parsing
fd-deterministic-multi-key-sorting
dasel-html-document-format
bandit-structured-nosec-directives
The verifier’s job
1. An agent attempts each task 4 times
2. Our model scores every step of every attempt
3. Average the last 12 step scores
4. Pick the attempt with the highest score
5. Did the picked attempt pass its tests?

38 held-out tasks, attempts by Claude Opus 5. Only 13 tasks are decidable: on the rest, every attempt passes or every attempt fails.
